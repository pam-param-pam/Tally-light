GETTING STARTED

Set up your tally system

Follow these four steps in order. You only need to download the connection profile once.

Need help?
  1. 1
    DESKTOP APP

    Download the transmitter

    Install the transmitter on the Windows computer that can reach your ATEM switcher.

    Open GitHub releases
  2. 2
    SECURE CONNECTION

    Download your connection profile

    The profile connects the transmitter and Tally Lights to this relay. Import it into the transmitter app.

    Open connection profile
  3. 3
    FIRST TALLY LIGHT

    Configure a Tally Light

    Connect a Tally Light by USB, open Configure Tally Light in the transmitter app, and save its settings.

    Read the Tally Light setup steps →
  4. 4
    GO LIVE

    Start transmitting ATEM state

    Choose your ATEM in the transmitter app and press Start. View the live dashboard as soon as the transmitter connects.

    Open live view
