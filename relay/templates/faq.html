Frequently asked questions

Setup instructions and solutions to common connection problems.

How do I configure my first Tally Light?
  1. Connect the Tally Light to the transmitter computer with a USB data cable.
  2. Open Configure Tally Light in the transmitter app and select the Tally Light’s serial port.
  3. Click Connect to Tally Light.
  4. Enter the Wi-Fi details, name, and ATEM source.
  5. Click Save to Tally Light. The app restarts the Tally Light, reconnects, and verifies its settings automatically.
Why can I not download the same connection profile again?

The relay returns the secrets only when they are created. It stores secure hashes afterward, which cannot be converted back into the original tokens. To get another file, rotate the credentials from Account. Rotation disconnects existing hardware until the new profile is imported and uploaded.

The Tally Light stays blue. What should I check?
  • Use a 2.4 GHz Wi-Fi network; ESP8266 Tally Lights cannot join 5 GHz-only networks.
  • Check the Wi-Fi name and password in the transmitter app.
  • Use a USB data cable, read the settings again, and save corrected values.
  • Restart the Tally Light after saving.
The Tally Light stays pink. What should I check?
  • Confirm the relay URL in the Tally Light settings ends with /ws/lights.
  • Confirm the current connection profile is loaded in the transmitter app.
  • If credentials were rotated, upload settings to the Tally Light again.
  • Check that the network allows outbound WebSocket connections.
The Tally Light is yellow and never changes.
  • Open View live and confirm the transmitter is connected.
  • Confirm the transmitter can reach the ATEM.
  • Check that the Tally Light’s ATEM source matches the camera input.
  • Make sure only one transmitter is connected to the relay.
The transmitter cannot import the connection profile.
  • Select the JSON file downloaded from Account without editing it.
  • Confirm the relay is reachable from the transmitter computer.
  • If the file is old, rotate credentials and import the newly downloaded profile.
USB settings cannot be read.
  • Use a USB cable that supports data.
  • Reconnect the cable and refresh the serial-port list.
  • Select the correct port and wait a moment for the board to restart.
  • Close other programs that may be using the serial port.
Can I run more than one transmitter?

No. The relay accepts one transmitter at a time so every Tally Light receives one authoritative ATEM state.
