What each Tally Light color means

Use the physical LED color to understand what the Tally Light is doing.

Blue

The Tally Light is connecting to Wi-Fi. If it stays blue, check the Wi-Fi name and password and confirm the network supports 2.4 GHz.

Pink

The Tally Light has Wi-Fi and is connecting and authenticating with the relay.

Yellow

The connection is ready, but no current program or preview state is available.

Green

The configured source is in ATEM preview. The camera is likely to go live next.

Red

The configured source is live on program.

Off

The source is neither on program nor preview, or the configured brightness is zero.
